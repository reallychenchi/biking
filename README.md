# 发心第一

解决骑行基础数据记录问题，不希望有其他功能打扰。

能记录骑行基础数据的软件很多，但是没有其他功能打扰的软件很少。

而且我发现这些软件的bug越来越多，就连基础数据也记不准，豆包写代码应该也不至于如此。

# 定位第二

用GPS/北斗定位，肯定很准，而且是两套，所以第二。

目标客户暂时定位为我自己好了，“许愿式编程”成本很低，安装软件还要安装，怎么比得过现写一个快？

# 设计第三

这种没有复杂度的小软件，GPT 5.6 sol做来是手拿把攥。

要什么设计？让GPT设计。

# 用户第四

用户需要有编程基础，能自己下载代码和配置xcode，找个mac上编译以后就能在iOS手机上用了。
这个要求不低，真的把用户放在第四位了。
未来没有上架计划，苹果商店太贵。

# 敏捷第五

骑行要敏捷，否则快不了。

# 秩序第六

骑行务必遵守交通规则，第六不代表不重要。

# 军争第七

和电瓶车、汽车争夺路权，要在遵守秩序的前提下，并且礼让行人，所以军争第七。

# 长期第八

能做到敏捷骑行、遵守秩序、适当争取路权的情况下，长期骑行是有益身心健康的。
